# 🍄 Mario Jump Game

Projeto inspirado no jogo offline do Google Chrome.

## 🎮 Sobre o Projeto

Jogo desenvolvido com:

- HTML5
- CSS3 (animações)
- JavaScript Vanilla

O objetivo é desviar dos obstáculos pulando no momento certo.

## 🚀 Funcionalidades

- Sistema de pulo animado
- Colisão com Game Over
- Contador de tempo (score)
- Botão de reinício
- Sons de pulo e derrota
- Botão mobile responsivo

## 📱 Responsividade

- Tecla qualquer para pular (desktop)
- Botão "Pular" em telas pequenas (mobile)
